# Delivery and evidence plan

## Milestone gates

- Foundation: monorepo, contracts, API health, schema, RLS, CI, responsive demo.
- Connected product: hosted Supabase Auth, workspace CRUD, private uploads, signed URLs.
- Review workflow: persistent annotations, comments, checklist, share tokens, immutable decisions.
- Public release: Railway API, Vercel web, security review, end-to-end tests, monitoring.
- Portfolio publication: real screenshots, public source URL, live URL, measured results, case study.

## Recruiter evidence to capture

Capture the landing page, dashboard, annotated review, guest decision screen, mobile review, OpenAPI documentation, and architecture diagram. Every metric must come from a recorded production test or analytics event; otherwise label it `TODO(content)`.

## Customer validation

Interview five agency or product-team leads. Record the current review process, frequency, cost of missed feedback, guest-access requirements, and willingness to pay. Do not claim product-market fit from compliments; require repeated use or payment intent.

## Deferred work

Video/PDF review, realtime presence, billing, AI, external integrations, custom domains, SSO, and native apps stay outside the MVP.
